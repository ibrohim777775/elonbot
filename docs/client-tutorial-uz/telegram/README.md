# Учебное видео в стиле Telegram

Готовый файл: **elonbot-telegram-uz.mp4**. Узбекский язык, 2:01, вертикальный формат 720×1280, 24 кадра/с. Пояснения встроены в кадр, озвучки и музыки нет.

В этой версии чат оформлен в стиле тёмной темы Telegram для Android: шапка, сообщения, время, галочки, клавиатура, пересылка альбома, выбор получателя, нажатия и смена статусов. Это учебная реконструкция, не запись настоящей переписки. Обозначение «O'QUV NAMOYISHI» остаётся в кадре.

Экран подключения групп снят в локальной тестовой Mini App проекта. Для него использовались временная база и вымышленные группы; Telegram не подключался. Чат отрисован по текстам `app/uz.json` и последовательности `app/bot.ts`. Фотографии квартиры сгенерированы для примера. Аккаунт в сценарии уже подключён; процесс входа не показан. Все сведения об отправке условные.

Лимит 30 групп приведён как пример тарифа. В ролике нет фиксированных цен и гарантии мгновенной доставки. Фотографии предлагается переслать готовым альбомом (до 10) и оставить сообщения в чате бота.

## Просмотр

Из корня проекта:

```powershell
python docs/client-tutorial-uz/serve.py
```

Откройте `http://127.0.0.1:8776/telegram/preview.html`. Сервер доступен только на локальном компьютере и поддерживает перемотку MP4. `steps.html` содержит все состояния без анимации. Видео не запускается автоматически; при включённом системном уменьшении движения переходы по главам оставляют его на паузе.

## Повторная сборка

Нужны Python, Pillow, шрифты Arial в Windows и FFmpeg с libx264. Первая версия видео сохранена в родительском каталоге.

```powershell
python docs/client-tutorial-uz/render_telegram.py --preview-only
python docs/client-tutorial-uz/render_telegram.py --ffmpeg node_modules/.cache/elonbot-video/ffmpeg-win-x86_64-v7.1.exe
```

Флаг `--reduced-motion` дополнительно позволяет собрать видео с затуханием вместо смещения и без расширения индикатора касания. Готовая альтернатива без движения — `steps.html`.
