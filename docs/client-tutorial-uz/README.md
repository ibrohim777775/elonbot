# Обучающее видео Elonbot на узбекском

**Новая версия в стиле Telegram:** [видео и инструкция](telegram/README.md), локальный просмотр — `http://127.0.0.1:8776/telegram/preview.html`. В ней используются реалистичный чат, пересылка альбома и настоящий экран Mini App из тестовой версии. Ниже описана сохранённая первая версия.

Основной файл: **elonbot-qollanma-uz.mp4**. Вертикальный формат 9:16, 720×1280, 24 кадра/с, 2:01. Крупные пояснения встроены в видео; озвучки и музыки нет.

Это анимированная учебная демонстрация со схематичным интерфейсом, а не запись реального Telegram-аккаунта. Названия кнопок сверены с `app/uz.json`, порядок шагов — с `app/bot.ts` и текущей инструкцией. Группы, объявления, изображения и результаты отправки условные. Реальные сообщения не отправлялись.

Видео предназначено для создания объявления **с уже подключённым аккаунтом**. Это условие показано в начале. Подключение по номеру, OTP и 2FA не входит в ролик: этот путь требует пересмотра согласно обзору от 28 сентября. Демонстрация не подтверждает, что вопросы платформы из обзора устранены.

В видео нет фиксированных цен и обещания мгновенной отправки. Лимит 30 групп помечен как пример; актуальное значение зависит от тарифа. Расписание показано по времени Ташкента. Отдельно объяснено, что пересланные фотографии нужно оставить в чате с ботом.

## Файлы

- `elonbot-qollanma-uz.mp4` — готовое видео для отправки клиентам.
- `cover.png` — обложка.
- `subtitles-uz.srt` — отдельные субтитры с тайм-кодами.
- `preview.html` — локальный просмотр с переходами по главам.
- `share-text-uz.txt` — узбекский текст для сообщения с видео.
- `scenes.json`, `render.py` — сценарий и воспроизводимая сборка.
- `storyboard.jpg`, `frames/` — контрольные изображения сцен.
- `verification.json`, `decode-check.log` — параметры и проверка декодирования готового файла.

## Повторная сборка

Нужны Python, Pillow и FFmpeg с поддержкой libx264. Использованный FFmpeg поставляется пакетом `imageio-ffmpeg 0.6.0`; локальная копия находится в игнорируемом кеше `node_modules/.cache/elonbot-video/`.

```powershell
python docs/client-tutorial-uz/render.py --ffmpeg node_modules/.cache/elonbot-video/ffmpeg-win-x86_64-v7.1.exe
```

Только контрольные изображения:

```powershell
python docs/client-tutorial-uz/render.py --preview-only
```

Просмотр с работающей перемоткой:

```powershell
python docs/client-tutorial-uz/serve.py
```

Откройте `http://127.0.0.1:8776/preview.html`. Сервер слушает только локальный компьютер и поддерживает запросы диапазонов для видео.

Проверка не запускает приложение, не читает `.env` и не подключается к Telegram. Код бота и публичный сайт в рамках создания видео не изменялись.
