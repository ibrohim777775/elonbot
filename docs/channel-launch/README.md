# Запуск информационного канала Elonbot

Название: **Elonbot | Yangiliklar va qo‘llanmalar**.

Канал пользователя: <https://t.me/+XE6Z-NQakcJkYjRi>. Это присланная владельцем пригласительная ссылка. Доступность и права администратора через Telegram не проверялись.

## Материалы для публикации

1. Установите описание из `description-uz.txt`.
2. Опубликуйте `01-welcome-uz.txt` как первое сообщение и закрепите его.
3. Прикрепите **видео**, а не ссылку на локальный просмотр: `../client-tutorial-uz/telegram/elonbot-telegram-uz.mp4`. Вставьте `02-video-caption-uz.txt` в подпись и опубликуйте. Это новая версия в стиле Telegram, 2:01, на узбекском, без озвучки.
4. После публикации скопируйте ссылку на пост с видео и при желании добавьте её в закреплённый пост как «🎬 Videoqo‘llanma». Ссылки на localhost и путь файла клиентам не отправляйте: они работают только на компьютере владельца.

Оба поста готовы для копирования. Цены и изменяемые условия бесплатного периода намеренно не зафиксированы: пользователи направляются к актуальным тарифам в боте. Подпись к видео укладывается в 1024 символа. Фактической публикации из рабочего окружения не было.

## Ссылка в боте

В приветствии после выбора языка, `/settings` и `/help` добавлена URL-кнопка:

- Узбекский: **📢 Yangiliklar va videoqo'llanmalar**.
- Русский: **📢 Новости и видеоинструкции**.

По умолчанию используется присланная владельцем ссылка. Открытие канала не меняет черновик объявления и не требует подписки для работы с ботом.

Для другого адреса задайте на сервере:

```dotenv
PUBLIC_CHANNEL_URL=https://t.me/+XE6Z-NQakcJkYjRi
```

Поддерживаются публичные адреса `https://t.me/username`, приглашения `https://t.me/+…` и `https://t.me/joinchat/…`. Пустое значение `PUBLIC_CHANNEL_URL=` скрывает кнопку. После изменения настройки перезапустите приложение. Если ссылка-приглашение будет отозвана, замените её этой настройкой.

Чтобы доставить изменения кода на сервер, сначала закоммитьте и отправьте их в репозиторий. Затем выполните на сервере обычное обновление:

```bash
sudo bash /home/deploy/update-elonbot.sh
```

Если `PUBLIC_CHANNEL_URL` ранее не был задан, дополнительных изменений `.env` для текущей ссылки не требуется. Проверка после обновления: откройте `/start`, затем `/settings` или `/help`, и нажмите кнопку канала.
