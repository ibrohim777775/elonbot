# Elonbot — выбранный логотип

Пользователь выбрал первый вариант «Объявления»: лаймовое сообщение с мегафоном на зелёном фоне.

Основной файл: [announcement-v1.png](../../public/site/brand/announcement-v1.png), 1254×1254. Это точная копия [первого варианта](alternatives/01-announcement.png), без перерисовки, изменения цветов и обработки. Исходник создан встроенным ImageGen; промпт находится в [alternatives/prompts.json](alternatives/prompts.json).

## Где используется

- Узбекская и русская версии сайта: шапка и подвал.
- Админка, мини-приложение с группами, справка на обоих языках и страница подключения Telegram.
- Иконки вкладок и ярлыков на домашнем экране всех этих страниц.
- Open Graph и Twitter: квадратный логотип в предпросмотре ссылки; заголовки и описания остаются локализованными.
- SEO-разметка Organization.

Для горизонтального логотипа используется исходное изображение рядом с текстом `elonbot` в HTML. Размер изображения задан заранее, чтобы избежать скачков вёрстки. Все страницы ссылаются на один файл `/site-assets/brand/announcement-v1.png`; новый адрес отделён от прежних изображений в кеше браузера.

## Telegram и публикация

Тот же PNG подходит для фото бота и канала. Смена фото в Telegram не выполнялась. После сохранения изменений в Git и отправки в репозиторий обновите сервер обычным скриптом проекта. Предпросмотры ссылок в мессенджерах могут обновляться с задержкой из-за их кеша.

## Проверка выбранного варианта

Сборка `npm run build` и 6 существующих тестов сайта и страницы входа прошли. В браузере проверены загрузка изображений и отсутствие горизонтального переполнения: сайт на настольном экране, русская версия, мини-приложение, справка на двух языках, админка и подключение аккаунта при ширине 390 px. Снимки: [сайт UZ](selected-site-uz.png), [сайт RU на телефоне](selected-site-ru-mobile.png), [подключение аккаунта](selected-account-mobile.png).
