# Три новых варианта логотипа Elonbot

1. **Объявления** — мегафон внутри сообщения, зелёный фон и лаймовый знак. Файл `01-announcement.png`.
2. **Расписание** — часы со стрелкой отправки, светлый фон. Файл `02-schedule.png`.
3. **Одно сообщение — несколько групп** — сообщение с тремя получателями. Файл `03-broadcast.png`.

Все три — отдельные квадратные PNG 1254×1254 с полями для круглой обрезки Telegram. Созданы встроенным ImageGen и скопированы в проект без изменения. Полные промпты находятся в `prompts.json`. Логотип E со стрелкой, уже подключённый к сайту, сохранён: новые файлы подготовлены как варианты для выбора.

Откройте `index.html`, чтобы сравнить варианты рядом, посмотреть круглую обрезку и небольшой размер. Для публикации скачивайте оригинальные PNG, а не снимок страницы сравнения.
